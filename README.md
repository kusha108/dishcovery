🍽️ Dishcovery – Recipe Sharing Platform

Dishcovery is a full-stack Recipe Sharing Web Application where users can explore, create, and manage delicious recipes. Built with the MERN stack, it provides a modern UI and seamless user experience.

🔗 Live Demo

👉 Live Website: https://dishcovery-4.vercel.app/


🚀 Features

👤 User Authentication (Register / Login)

🍲 Add New Recipes

📖 View All Recipes

❤️ Like / Save Recipes

✏️ Edit & Delete Recipes

📸 Image Upload Support

🔐 Protected Routes

🌙 Modern UI with Light/Dark Theme

📱 Fully Responsive Design
